// Features

🎮
Full ADOFAI Player
Play any .adofai level in your terminal with perfect timing accuracy, orbit physics, and real-time scoring.
✏️
Vim-Style Editor
Create and edit levels with vim-like keybindings, undo tree, mouse support, and real-time preview.
🎨
Shader-Like Effects
Bloom, scanlines, CRT distortion, chromatic aberration, vignette, screen shake — all in your terminal.
🔥
Particle System
Hit sparks, fire trails, ice crystals, rainbow particles — cinematic feedback for every input.
📹
Cinematic Camera
Smooth follow, zoom, rotation, pulse, and shake. Every ADOFAI camera event is supported.
🖥️
120 FPS Rendering
Custom framebuffer with diff rendering. Only changed cells are redrawn — buttery smooth at 120 FPS.
🎵
Audio Engine
Built-in audio playback with hitsounds. Supports MP3, WAV, OGG, and FLAC formats.
⏪
Replay System
Record and replay your runs with slow motion, frame advance, and hit analysis.
🎭
7 Built-in Themes
Neon, Retro, Minimal, Fire, Ice, Synthwave, Matrix — each with unique post-processing effects.
📊
Level Analyzer
BPM graphs, angle distribution, density visualization, event summaries — understand any level at a glance.
🧩
Full .adofai Support
Parses and generates real ADOFAI files. angleData, pathData, actions, decorations — everything.
📦
Single Binary
Written in Rust. Zero runtime dependencies. Cross-platform. One binary, instant startup.

// Documentation

Quick Start

# Create a new level
adofai new --bpm 180

# Edit the level
adofai edit untitled.adofai

# Play the level
adofai play untitled.adofai

# Play with a theme
adofai play level.adofai --theme neon

# Analyze a level
adofai analyze level.adofai

Commands

CommandDescription
play <file>Play an ADOFAI level in the terminal
edit <file>Open the map editor
newCreate a new empty level
render <file>Render a level (auto-play capture)
replay <file>View a saved replay
theme <name>Preview and info about a theme
analyze <file>Show level statistics and analysis

Architecture

adofai-cli/
├── src/
│   ├── renderer/     Custom framebuffer + diff rendering
│   │   ├── framebuffer    Cell-based terminal buffer
│   │   ├── pipeline       Render pipeline orchestration
│   │   ├── post_process   Bloom, CRT, scanlines, glitch
│   │   ├── particles      Spark, fire, ice, rainbow
│   │   └── unicode_pixel  Braille + block rendering
│   ├── engine/       Game engine
│   │   ├── game           Main game loop (120 FPS)
│   │   ├── tile           Tile geometry + rendering
│   │   ├── planet         Orbit physics + multi-planet
│   │   ├── timing         Beat sync + hit accuracy
│   │   └── input          Key + mouse handling
│   ├── editor/       Map editor
│   │   ├── editor_state   Full TUI editor with modes
│   │   └── undo           Branch-based undo tree
│   ├── parser/       .adofai file parser
│   │   ├── adofai         Level file I/O
│   │   └── events         All event type definitions
│   ├── camera/       Cinematic camera system
│   ├── effects/      Visual effects + themes
│   ├── audio/        Rodio-based audio engine
│   ├── replay/       Record/playback system
│   └── cli/          CLI command handlers
